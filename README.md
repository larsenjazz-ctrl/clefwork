# Clefwork

Music theory quizzes that run entirely in the browser — no server, no accounts, nothing stored online.

- **Landing page:** [index.html](https://larsenjazz-ctrl.github.io/clefwork/) — choose a tool, or paste report codes and results links to open them in the grade checker. Each teacher tool has an **← All tools** link back here. Old `index.html#grade=…` and `#take=…` links are passed on to the quiz builder.
- **Teacher app:** [clefwork.html](https://larsenjazz-ctrl.github.io/clefwork/clefwork.html) — build a quiz, share its code or link, and grade the report codes or results links students send back.
- **Student app:** [student.html](https://larsenjazz-ctrl.github.io/clefwork/student.html) — practise with instant feedback, or take a teacher's quiz and send back a report code.
- **Clefwork Keys:** [keys.html](https://larsenjazz-ctrl.github.io/clefwork/keys.html) — a separate app for reading notes: the grand staff, note names with octaves, and the piano keyboard.
- **Clefwork Analysis:** [analysis.html](https://larsenjazz-ctrl.github.io/clefwork/analysis.html) — harmonic analysis on real music: upload a picture of a score, box the chords, and students write Roman numerals or chord symbols beside the music.
- **Clefwork Rhythm:** [rhythm.html](https://larsenjazz-ctrl.github.io/clefwork/rhythm.html) — rhythmic dictation: students hear a rhythm in one or two parts and write it on a one-line staff; or a rhythm grid: students show where each note starts and how long it lasts on a grid of beats and boxes.
- **Clefwork Melody:** [melody.html](https://larsenjazz-ctrl.github.io/clefwork/melody.html) — melodic dictation: students hear a melody of up to eight measures and write its pitches and rhythm on the staff.
- **Clefwork Chord Graph:** [graph.html](https://larsenjazz-ctrl.github.io/clefwork/graph.html) — the chord graph as worksheets: diatonic progression tables, tritone substitution graphs, and phrases in Roman numerals checked against the graph's rules.
- **Clefwork Terms:** [terms.html](https://larsenjazz-ctrl.github.io/clefwork/terms.html) — musical terms, multiple choice: dynamics, tempo markings and instrument families, and hearing the dynamics and tempo of a generated melody.
- **Canvas pages:** [take.html](https://larsenjazz-ctrl.github.io/clefwork/take.html) takes one quiz and ends with a results link to hand in; [results.html](https://larsenjazz-ctrl.github.io/clefwork/results.html) shows one student's results from that link.

## How it works

A quiz's settings and a random seed are packed into a **quiz code**, so everyone who opens the same code gets the same questions. When a student finishes, their name, score, timings and answers are packed into a **report code** that the teacher pastes into the Grade reports tab, where the answers can be viewed on the staff. Both codes carry a checksum, and report codes also carry a seal tied to the quiz.

Question types: place a note, name a note, intervals (simple and compound), chords (triads through 13ths, inversions, typed chord symbols), scales (including pentatonics and modes), key signatures, chord progressions, figured bass (single chords and progressions), and voicings — single voiced chords and voiced progressions.

### Voicings

Two tabs build chords from the teacher's complexity settings (sizes, qualities, altered notes, chords from a key or chromatic, slash chords) and voice them with a named technique: stacked thirds, chorale, block voicing, drop 2, drop 2 & 4, 5 plane / 9 plane, pop horn voicings, inner sevenths, or a voicing the teacher writes out. Each technique has its own counter and its own choices — staff, open or closed, three or four notes, inner 2nds. Students either write the notes for a printed chord symbol, or write the chord symbol for a printed voicing.

### Scale degrees

The **Scale Degrees** tab in the quiz builder prints melodies of one to eight measures, made by Clefwork Melody's generator, with their key signatures. Students choose the scale degree (1–7) under every note, and each note is an equal share of the question. The teacher picks the length, the melody level, major, minor or both, how many sharps or flats, the clefs, and whether students may play the melody and the tonic chord. The melodies have no chromatic notes; in minor keys a raised 6th or 7th is still 6 or 7. Printed copies show the melody with room to write the numbers under the notes.

### Clefwork Keys

A separate app, built on the same engine, for one skill: knowing a note in three forms. Each question shows a note one way — **on the grand staff**, **as a name with its octave** (F♯4; middle C is C4), or **as a highlighted piano key** — and asks for it another way: **write it on the grand staff**, **type the name**, or **play it on the piano**. The teacher picks which ways to show and which ways to answer, and the quiz mixes every pairing that isn't simply copying. The piano plays each note as a key is pressed, a name is typed, or a note is written.

Octaves always count. A piano key has no spelling, so when a key is shown either name for it is right (C♯4 or D♭4); a note on the staff has one spelling unless the quiz accepts enharmonic spellings. Keys quizzes use the same quiz codes, report codes, grade checker, Canvas pages and printing as the main app.

### Clefwork Analysis

A separate app, built on the same engine, for analysing real music. The teacher uploads a picture of a score — a scan, an export from notation software, or a screenshot — and drags a box around each chord or passage to ask about. For each box Clefwork asks whether students should write a **Roman numeral**, a **chord symbol**, **both**, or name its **non-harmonic tones** (below); the teacher types the answer and saves the box before drawing the next one. A quiz-wide setting can switch every box to Roman numerals, chord symbols, or both, and lists any box that lacks an answer for it. A box can accept more than one answer (`I64, Cad64`).

Students see the whole score with each box lightly highlighted in its own colour. Their answer boxes sit outside the music — chord symbols above each system, Roman numerals below — centred under the part they refer to, numbered and tinted to match. A small key reminds them what the figures mean (6, 6/4; 7, 6/5, 4/3, 4/2) and how to type them: there is no figure dropdown, just `V65`, `ii6`, `vii°7` (or `viio7`), `viiø7` (or `vii/o7`), `V7/V`, `N6`, `Ger+6`. Roman numerals are marked by what they mean, so `V65` and `V6/5` are the same answer; chord symbols follow the same rules as the rest of Clefwork (mi, ma, °, ♭/♯, slash chords). With partial credit on, a box that asks for both earns half for each.

**Non-harmonic tones.** A box can instead ask for the non-harmonic tones in it. The teacher clicks each one inside the box to circle it (the circle size can be changed) and names it from the list: non-harmonic tone (NT, any kind), passing tone, accented passing tone, neighbor tone, upper and lower neighbor, accented neighbor, incomplete neighbor, appoggiatura, escape tone (échappée), double neighbor (changing tones), suspension, retardation, anticipation, pedal point, chromatic passing tone and chromatic neighbor. Two circles can be **joined with a line** and named as a pair — the dissonance and the note it resolves to (or, for an anticipation, the note it arrives early at): a 9–8, 7–6, 4–3, 2–3 (bass) or 6–5 suspension, a 7–8 or 2–3 retardation, or an anticipation, or just "suspension" or "retardation". Either students **find and circle the notes** themselves — click a note in the box to circle it, choose what it is from a menu, "Join to…" another circle for a pair — or the notes are **circled for them** and they only name them. The teacher chooses which kinds are in the students' menus (any kind a box's answer uses is added). Grading: a circle counts when its centre falls on one of the teacher's circles, and is right with the right name — a general answer accepts its kinds (NT any kind; neighbor tone an upper or lower neighbor; suspension or retardation any of theirs); a pair is right when both its circles are on the teacher's pair and it has the right name. A box earns its share of what's right, less one for every circle or pair that matches nothing, never below nothing. The grade checker shows the student's circles marked right or wrong and what they missed dashed.

**Linked Roman numerals.** A Roman numeral box can be linked to the next box — the same chord, its figures changing, as in a cadential V 6–5 over 4–3, or I 9–8. Students type the numeral and figures in the first box (V64) and just the figures in the next (53); a line joins the two boxes on their sheet. The figures are read as intervals above the bass, so suspensions like V4 → 3 work too, and the second box also accepts the numeral typed again (V53).

**The opening key.** Each score has an **Opening key** setting above the music: **Not shown** (the default — the teacher can still give the key in the instructions), **Shown to students** ("Key: D major" above the music), or **Students identify it**, a question with a menu of every major and minor key, right only for the exact key. A library piece fills in its key, left Not shown, so it's never given away by accident; the builder warns when the instructions mention a key while students are asked to identify it.

**Key changes.** Each score can mark where the key changes: draw a box around the chord where the new key begins and choose **Key change**. The teacher chooses whether students **see it highlighted** (labelled with the new key, if one is given — a marker that tells them where the new key starts, not a question) or **find it and box it themselves**, and can ask them to **name the new key** from a menu of every major and minor key (half a point each when they find it too). Key changes are numbered on their own — Key change 1, 2 … in reading order — so a hidden one's number doesn't give away where it is among the boxes. Students find one by choosing **Draw the box** in its panel above the music and dragging across the chord (zooming in first helps). Their box counts when each side is within 15% of the width of the teacher's box (Close 10% and Loose 25% are under Answers), and at least 60% of it lies within the teacher's box's height — it needn't reach from top to bottom. The grade checker shows the student's box, marked, over the answer's dashed box.

**Zoom.** "🔍 Zoom 2×" makes the music twice as big — for students, centred on the box they're answering and following them from box to box (the − and + buttons still go from 100% to 250%); for the teacher, while drawing boxes and circling notes.

**Trimming.** Besides the empty margins, a wide empty band inside the picture — the rest of a page between the music and a footer, say — shrinks to a small margin. A draft made before this keeps its old trim when its picture is uploaded again, so its boxes stay put.

Codes: linked boxes, boxes of non-harmonic tones, key changes and opening keys are written at the very end of the quiz code (after any ties), so analysis quizzes without them keep exactly their codes, and an older Clefwork shows a box of non-harmonic tones as an empty Roman numeral box (and leaves out key changes). Students' circles, boxes and keys go at the end of the report code the same way. Boxes and key changes are numbered system by system and, where the picture runs two systems together, line by line.

A quiz can be on **several scores** — up to six, each with its own boxes. "+ Add a score" (once the first has its picture) adds a tab; each score is uploaded, chosen from the library or chosen at random, and named for students ("Score 2 — Chorale No. 26"). Students see the scores one after another, each under its name, and the boxes are numbered on from one score to the next. Quiz extension 12 carries the other scores' boxes and names; one-score quizzes keep exactly the codes they had.

The picture travels inside the quiz link as a compressed black-and-white copy — about 8–15 KB for a passage, more for a dense full page — so nothing is hosted anywhere. Detail (Standard, High, Highest) and ink (Lighter, Normal, Darker) trade link length against sharpness. With several scores, each picture travels in the link (&img=, &img2= …). The quiz code on its own doesn't carry the pictures, so students open the link; the code still works for grading on another computer. Report codes, the grade checker, results pages and Canvas work as they do everywhere else, and the grade checker shows each box cropped from the score with the student's answers marked. Analysis quizzes don't print.

### Clefwork Rhythm

A separate app, built on the same engine, for rhythmic dictation. The teacher writes each example on a one-line staff, or lets Clefwork make them; the computer plays each one and students write what they hear.

- **Made automatically.** The teacher chooses how many examples (up to 20), how many measures in each, the tempo (as a quarter note; other meters keep the same speed of eighth notes), and a level:
  1. *Very easy* — 4/4, quarter notes and longer, every note on a beat; rests in up to a fifth of the measures.
  2. *Easy* — 2/4 to 4/4, eighth notes and longer, no note starting off the beat; rests in up to 30% of the measures.
  3. *Medium easy* — 2/4 to 4/4, eighth notes and longer, one or two notes off the beat; rests in 10–40% of the measures.
  4. *Medium* — 2/4 to 6/4, and 3/8, 6/8, 9/8 and 12/8, eighth notes and longer, one or two notes off the beat; rests in 20–50%.
  5. *Advanced* — any time signature, sixteenth notes and longer, notes off the beat; rests in 30–70%, including ones that make the rhythm harder.
  6. *Very hard* — any time signature and any rhythm, triplets included; rests in 40–80%.
  7. *Custom rules* — a range of time signatures from 2/4 to 6/4, plus compound meters, cut time (and 3/2) or uneven meters; the shortest note; dotted notes; triplets; none, one or two, or more notes off the beat; and no rests, a few, some or many.

  Each measure is built beat by beat from short rhythmic cells chosen for the level, in a phrase that repeats measures (A A B A, A B A B …), and the clearest of many tries is kept: about four to eight notes in a 4/4 measure, long notes with short ones, no more than one syncopation a measure (one or two in the whole example at the easier levels), and a long note to end. Rests go in the share of measures the level calls for, and never fill more than half of a measure. Easy levels use quarter and half rests on the beat and an eighth rest after an eighth; harder levels add the rests that make a rhythm harder — a rest on the beat before an entry, sixteenth rests, a rest inside a triplet — and may start an example on a rest. The quiz's seed picks everything, so the quiz code carries only the settings and every student gets the same examples; "Make new examples" picks a new set. The generator is versioned in the code, so a quiz shared earlier keeps the examples it was made with.

  **Ties** (a switch, at any level): some notes are tied to the next — held over the bar line, or an off-beat note held over the next beat — about one tie every two measures, never inside a triplet. The ties are added after the rhythm is made, so turning them on doesn't change the rhythms otherwise.
- **Examples.** A quiz holds up to 12 examples, each one to four measures long, in 2/4 to 6/4, 3/8 to 12/8, or 2/2 and 3/2, with its own tempo. Irregular eighth-note meters (5/8, 7/8, 8/8, 10/8, 11/8) choose how their eighths group into beats (7/8 as 2+2+3, 3+2+2 or 2+3+2), which sets the beaming and the metronome.
- **Writing a rhythm.** Note values from sixteenths to whole notes, with rests. To write a dotted note or a triplet, turn on Dot or Triplet, then choose the value; both stay on until turned off. A caret shows where the next note goes, a clicked note is selected and replaced by the next value chosen, and a full measure moves the caret on. **Tie** joins the note just written (or the one clicked) to the next note — in the same measure or over the bar line — and choosing it again removes the tie; a tie drawn short is waiting for its next note. Keys: W H Q E S for the values, period (or D) for Dot, T for Triplet, R for Rest, ~ for Tie, arrows to move, Backspace to delete.
- **Full measures.** Every measure is checked against the time signature as it's written — a note that doesn't fit is refused, with how much room is left — and a quiz can't be shared until every measure is full (rests count) and every tie goes to a note.
- **Triplets** start on a beat: a quarter-note triplet on any beat, an eighth-note triplet on a beat. A triplet group shorter than the beat — sixteenth-note triplets in quarter-note time — may also start halfway through a beat. Mixed triplets (a quarter-note and an eighth-note triplet) are fine; a triplet that breaks these rules is refused as it's written.
- **Two parts.** A second part, with stems down, can have its own rhythm. The part with stems up plays on the piano, the part with stems down on the oboe.
- **Listening.** Students choose which measures to play (tap one, drag across several, or All), a count-off of none, one or two bars, and whether the metronome clicks under the music. Each instrument and the click has its own volume slider. They can also hear what they've written, on the same instruments. The teacher sets how many times students may play each example, and their own answer, before submitting (unlimited, or once to 10 times); every play counts, whatever it covers. Once an answer has been checked, plays are unlimited.
- **Scoring.** Graded note by note, by what sounds. Each note of the answer is right when the student has a note that starts at the same moment, in the same part, and lasts as long; a missing note, a note of the wrong length, and every extra note the student writes are each a wrong note. Rests only fill time, so a quarter rest and two eighth rests are the same answer; tied notes are one note that lasts as long as both, so a half note and two tied quarters are the same answer too, and a tie over the bar line is one long note. Tied notes play as one. The teacher chooses how the quiz is scored: a point for every note (a quiz with 48 notes is out of 48, less one for each wrong note), or a percent of a total they set (the share of notes right, scaled to, say, 20 points). A question never scores below nothing.
- **Ties in the codes.** A quiz's ties, and a student's, are written at the very end of the quiz or report code, so codes without ties are exactly what they were, and an older copy of Clefwork reads a tied code with the notes untied. Rhythm grids don't use ties (a note on a grid stays in its row).
- **Results.** Report codes (version 11 and later) carry every note the student wrote, how often they played the example and their answer, and each example's notes and wrong notes. The grade checker and results pages show the score, the wrong notes, the student's rhythm with each note marked right or wrong, and the right rhythm beneath it with the missed notes marked — both playable — and the play counts.
- **Printing.** The Print tab prints each example's tempo and a blank one-line staff with its time signature, two measures to a line, for dictation on paper.

#### Rhythm grids

The second quiz type in Clefwork Rhythm (chosen under **Quiz type**). Students get a table with a row for each measure and the beats across the top, each beat split into boxes, as on a worksheet. For each note they click the box where it starts and choose its value, then drag its arrow across the boxes it lasts — with sixteenth-note boxes, a half note starts in one box and reaches across eight.

- **The grid.** Each box is a sixteenth, eighth or quarter note, as the teacher chooses. The rhythm is *shown* in notation above the grid (as on a worksheet), *played* (with the same listening controls and play limits as dictation), or *shown and played*. Rests are left blank, or marked and graded like notes.
- **Examples.** Written by the teacher — one to four measures, one part, no triplets, nothing shorter than a box — with the number of the first measure, so an excerpt's rows read m. 46, 47 … (a new example carries on the numbering). The builder draws the answer on its grid as the rhythm is written, and says what doesn't fit (a dotted-quarter beat can't be split into quarter-note boxes). Or made automatically at the same levels, one to four measures, leaving out triplets, notes shorter than a box, and meters whose beats don't split into boxes.
- **Writing the answer.** Click a box, or drag across several, then choose a value (W H Q E S, with Dot and Rest); drag a note's arrow, or use Shift + → ← or the Longer and Shorter buttons, to set how many boxes it covers. Arrow keys move between boxes and measures, and a note's value can be changed in place. On a narrow screen the grid scrolls sideways.
- **Scoring.** A note is right when it starts in the right box, has the right value (and dot), and covers the right number of boxes; a note missed or wrong, and every extra one, is a wrong note. Scored by notes or as a percent of a total, as dictation is.
- **Results and printing.** Report codes (version 14) carry each student's grid; the grade checker shows it marked, with the answer beneath. The Print tab prints the rhythm and an empty grid, like the worksheet it's modeled on.

### Clefwork Melody

Melodic dictation, built on Clefwork Rhythm: the same levels, meters, listening controls, play limits and scoring, with pitches on a five-line staff.

- **Made automatically.** The teacher chooses how many melodies (up to 20), one to eight measures in each, major keys, minor keys or both, key signatures up to 0–7 sharps or flats, treble clef, bass clef or both, the tempo, whether to allow chromatic notes, whether to tie some notes (as Clefwork Rhythm's **Ties**; a note tied over the beat takes the next note's pitch, an anticipation, or the next takes its pitch, keeping within the level's leaps), and a level. Each level uses the rhythms of the Clefwork Rhythm level with the same number, and adds the pitch rules below; *Custom rules* adds a range and a largest leap to the rhythm rules.
  1. *Very easy* — do to sol: steps and repeated notes, the odd skip within do-mi-sol.
  2. *Easy* — within a sixth: steps, and skips within the tonic chord.
  3. *Medium easy* — within an octave: leaps in the tonic and dominant chords, and phrases that end on the dominant, then the tonic.
  4. *Medium* — within a ninth: 4ths, 5ths and the odd 6th between chord tones, IV and V7 as well, and a sequence now and then.
  5. *Advanced* — up to a tenth: leaps up to a 6th, and octaves upward.
  6. *Very hard* — up to an eleventh: any leap up to an octave, 7ths in the dominant seventh.
- **How the melodies are made.** The generator follows what studies of folk songs, hymns and sight-singing books find about real melodies (Huron 1996; Vos & Troost 1989; von Hippel & Huron 2000; Krumhansl & Kessler 1982; Temperley 2007; the AP Music Theory course description, Ottman & Rogers and Karpinski for the levels). A melody is built in phrases of two or four measures — the second phrase often repeats the first one's rhythm — and each phrase takes a contour in the proportions the corpora show: arch most often, then descending, ascending and U-shaped. Steps and repeated notes make up about 90% of the moves at level 1 and about 70% at level 6, a little over half of all moves fall; small intervals tend to fall and large ones rise; a leap is followed by a step back toward the middle; and there are never more than two leaps in a row. Pitches are weighted by the key's tonal profile, with chord tones on strong beats and long notes, fa and ti off the beat, openings on do, mi or sol, half cadences on re, ti or sol, and an ending on do, most often stepping down from re. Rests come mostly between phrases, as breaths — none inside a phrase at levels 1 and 2, a few at the higher levels — and phrase-final notes are longer. In minor, the raised seventh leads to the tonic and the raised sixth only rises to it; the natural forms fall — and there are never augmented seconds or other awkward intervals. The quiz's seed picks everything, so the quiz code carries only the settings; the generator is versioned, so a shared quiz keeps its melodies.
- **Chromatic notes.** Off, every note belongs to the key (with the raised sixth and seventh in minor). On, the levels add chromatic notes as music uses them, a half step from the note they lead to and off the beat: lower neighbours (G F♯ G) from level 1, chromatic approach notes from level 3 (♯4 to 5 most often, then ♯1 to 2 and ♯5 to 6), and from level 5, in major keys, lowered notes that fall by step (♭7 to 6 most often, and ♭6 to 5, ♭3 to 2).
- **Written by the teacher.** Up to 12 melodies, each with its own key (major or minor, up to seven sharps or flats), clef, time signature (as Clefwork Rhythm), one to eight measures and tempo.
- **Writing a melody.** Click the staff where the next note goes — the height sets its pitch — then choose its value, or type the letter name (A–G) for the nearest note with that name. Notes take the key signature. A note can be dragged up or down, or moved with ↑ ↓ (Shift for an octave), and ♯ ♭ ♮ change the note just written or clicked; accidentals carry through the measure as in print. **Tie** works as in Clefwork Rhythm, over bar lines and line ends too; tied notes keep one pitch — the note after a tie starts on it, and moving either note moves both — and a note tied over the bar line doesn't repeat its accidental. Keys: 1 2 4 8 6 for whole to sixteenth, period for Dot, T for Triplet, R for Rest, ~ for Tie, + − = for sharp, flat and natural. Every note sounds as it's written. The staff shows up to four measures a line, fewer on a narrow screen.
- **Listening.** As Clefwork Rhythm, on the piano, plus **Hear the key** — the tonic arpeggio and chord, which doesn't use up a play. The teacher can tell students the first note: it's shown with the key and tempo, and the staff's cursor starts on it.
- **Scoring.** Note by note, by what sounds: a note is right when the student has a note that starts at the same moment, lasts as long and has the same pitch — enharmonic spellings count as the same note, and tied notes are one note, as in Clefwork Rhythm. The teacher chooses whether a note needs both pitch and rhythm right for its point or earns half a point for each, and scores the quiz by notes or as a percent of a total, as in Clefwork Rhythm.
- **Results.** Report codes (version 12) carry every note the student wrote and each melody's wrong pitches and rhythms. The grade checker and results pages show the student's melody with each note marked, the right melody beneath with the missed notes marked, both playable, and "1 wrong of 13 (1 pitch, 0 rhythm)".
- **Printing.** The Print tab prints each melody's key, meter, tempo and first note (when given) and blank staves with the clef and key signature, two measures to a line.

### Clefwork Chord Graph

A separate app, built on the same engine, for the chord graph: a key's chords laid out in the order their roots fall by fifths — vii° iii vi ii V I, with the relative minor's VII III VI ii° V i under them — the chords that can stand in (IV for ii; vii° or IV for V; in minor iv for ii°, VII or iv for V), and each chord's tritone substitute: the dominant seventh a half step above the chord it leads to (♭II7 of the next chord), which is a tritone from the chord it replaces wherever the graph falls a perfect fifth. Three worksheets, each with a counter:

- **Diatonic progression table.** The major key's Roman numerals over boxes for their chord symbols, the relative minor's beneath, and the common-tone substitutions above and below (IV, then vii° or IV; iv, then VII or iv). The teacher chooses whether the numerals are printed or written by students too, and whether to include the substitutions. A box with two answers ("vii° or IV") takes them in either order.
- **Tritone substitution graph.** I vii° iii vi ii V I in the major key and its relative minor, with a row of tritone substitutes above the major chords and below the minor ones. The first chord of the major row is printed to give the key. In minor, VI falls to ii° by a tritone, so VI's substitute is a perfect fifth above it — B♭7 for E♭ in G minor, the tritone substitute of V7/ii° from melodic minor's raised sixth. It looks wrong but is right, so its box is in italics on screen, in the answer key and in the grade checker. Either spelling of a substitute counts (C♭7 or B7); the answer key shows the simpler one (fewer sharps or flats, and ♭II of the chord it leads to on a tie). The chords' numerals can be shown above them, or hidden as on the worksheet.
- **Musical phrase.** Students write a phrase in Roman numerals, one chord a measure, on two lines of four (or one line of four), in a major key, a minor key, or both taking turns. The chord graph can be drawn beside it. Each measure earns a point when its chord is one of the key's (I ii iii IV V vi vii°; in minor i ii° III iv V VI VII, as triads or sevenths, in any inversion) and — with the graph rule on — follows from the chord before: one column to the right, staying put, anywhere from the tonic, or from V to vi, iii (deceptive) or IV (then I). The other rules, each a point: start on the tonic; end on the tonic after V, vii° or IV (V, VII or iv); and, in eight measures, a half cadence on one of those in measure 4. Students can also be asked for the chord symbols, in a key the quiz picks, each marked against the numeral above it. Students hear their phrase in that key; the answer key gives an example that keeps every rule.

Every table is in one major key and its relative minor, and every phrase in one key, dealt from the keys the teacher picks (from seven flats to seven sharps) so a quiz's worksheets are in different keys while the choice lasts. Chords are triads (B♭, Cmi, A°) or sevenths (B♭ma7, Cmi7, Ami7♭5); tritone substitutes are always dominant sevenths. The relative minor can be printed or left for students to work out (the diatonic table then has a box for its name). Students type chord symbols the way they would write them — B♭ or B♭Δ, Gmi, Gm or G-, A°, Ao or Adim, Ami7♭5 or Aø — and a box turns amber while it can't be read. Quality can count in full, earn half when only the root is right, or be ignored ("the root and, preferably, the quality"); Roman numerals work the same way with the degree. Scoring is every answer a point (as a worksheet is marked by hand), each table or phrase one question, or a percent of a total. Each table row of chords has a play button.

Codes: quiz extension 9 holds the settings (other quizzes keep their codes). Report codes carry each box as the chord read from it — root, quality, and whether it was a bare triangle or had anything after the root — or as text when it isn't a chord, and phrases as their numerals; with answer scoring, each question's points and the points lost in halves. The grade checker and results pages show each table with every box marked and the right answer under the wrong ones, and each phrase with its measures, the reason a measure lost its point, and the rules kept. The Print tab prints the worksheets as tables with empty boxes to write in, and the phrases as measures between double bars under the chord graph.

### Clefwork Terms

A separate app, built on the same engine, of multiple-choice questions in five kinds, each a tab with its own counter. The teacher sets how many choices each question has (3–6).

- **Dynamics.** ppp to fff, sfz, fp, cresc., decresc., dim. and the two hairpins, shown as printed in music (bold italics; hairpins drawn). Ways of asking: what a marking means, the marking for a meaning, its Italian name, or which of several is the loudest or softest. Markings that mean the same thing (decresc., dim., >) never share a question.
- **Tempo.** Grave to Prestissimo, plus accelerando, ritardando, rallentando, a tempo and rubato: what a term means, the term for a meaning, which is fastest or slowest, or about how many beats a minute (the usual metronome ranges). Tempos next to each other (Largo and Lento) never share a question.
- **Instruments.** The teacher picks instruments in five families — woodwind, brass, string, percussion, keyboard (off by default, since classes differ on the piano); a family with none picked is left out. An instrument's family, which of several is in a family, or which one isn't. Tricky ones (saxophone, flute, French horn, English horn, harp, timpani, mallet percussion) explain why with the answer.
- **Hear Dynamics.** A melody from Clefwork Melody's easy level, played twice — louder, softer or about the same the second time; or the first time at mf, which marking fits the second — or once: crescendo, decrescendo, steady or a sudden change. The levels are about 5½ dB apart on a bus that skips the compressor, and louder notes are brighter. A sound check sets the volume.
- **Hear Tempo.** The melody at a tempo to name (Largo 50 to Presto 184 beats a minute), twice faster or slower, or once speeding up, slowing down, keeping steady, or slowing then a tempo; with or without a click on every beat. Short melodies at fast tempos play through more than once.

- **Vocabulary.** The bold-face terms of the course textbook (*Harmony in Contemporary Music*) as the book defines them, each answer giving its page, plus other common terms, in ten categories the teacher picks: pitch & notation, rhythm & meter, scales & keys, intervals, chords, analysis & form (the textbook's), and articulation & expression, repeats & road maps, texture/ensembles/techniques, melody & harmony (common terms). A switch keeps to the textbook's own terms. Students choose a term's definition or the term for a definition; the wrong choices come from the same category first. A general term never sits beside a specific one it also describes (interval and perfect interval, inversion and first inversion), and synonyms (half step and semitone) never share a question. The builder lists every term and definition for checking.

Listening choices can be far apart (easier) or close together, and plays can be limited per question. The listening tabs can also play melodies from the library (below) instead of Clefwork's own. Codes: quiz extension 10 holds the settings; every Terms question is report type 21 (`term`), carrying the choice and, for listening, the play count — other quizzes keep their codes. The grade checker splits the score by kind, and the Print tab prints the markings with A–D choices.

### The library

Public-domain pieces to use as musical examples, in three kinds — **solo melodies**, **piano**, and **several instruments or voices** — each marked as one that can be heard (its notes are in the library) and/or one with a score picture:

- **Solo melodies (235):** 199 hymn tunes; 20 art-song vocal lines (Brahms, Schubert, Schumann, Fanny Hensel, Johanna Kinkel, Josephine Lang …) from the OpenScore Lieder Corpus (CC0); and 16 well-known tunes entered by hand (Twinkle, Frère Jacques, Ode to Joy, Jingle Bells, Minuet in G, the openings of Für Elise and Eine kleine Nachtmusik …), marked *Entered for Clefwork — please proofread against a score*.
- **Piano (74):** 73 public-domain pieces from the Mutopia Project (Bach, Beethoven, Burgmüller, Chopin, Czerny, Debussy, Grieg, Handel, Joplin, Kuhlau, Mendelssohn, Mozart, Satie, Schubert, Schumann, Tchaikovsky, Turpin), each with its first page as a score picture; 59 can also be heard, from their MIDI files (spelling inferred). Plus Bach's C-major Prelude opening, entered by hand.
- **Several instruments or voices (218):** four-part (SATB) hymns from the Open Hymnal Project, public domain, each with an engraved score and all four voices to hear.

Where it's used:

- **Clefwork Melody** and **Clefwork Rhythm** have a third way to fill the quiz beside writing the examples and making them automatically: **Choose them from the library**. Clefwork chooses at random — how many, how many measures each, from which kinds of piece, up to how many sharps or flats (and for a rhythm, one part or two) — and the teacher can swap any one for another (🎲 Another), remove it, or choose one themselves (choose a piece, a part — any voice of a hymn, a hand of a piano piece — and up to eight measures, or four for a rhythm). Ties are kept, over the bar line too (a tie out of the last measure taken is dropped); measures with a chord in a melody, or a rhythm Clefwork doesn't write, are passed over. The notes are copied into the quiz, so the quiz code carries them and "Write … myself" can still edit them.
- **Scale Degrees** works the same way when its melodies are "Chosen from the library" (quiz extension 11 carries their notes), passing over measures with ties, since every note gets a number.
- **Clefwork Analysis** can use a library score as if it were uploaded — choose one, or "🎲 A score at random" — from the 291 pieces with scores, more than can be heard.
- **Clefwork Terms**' listening tabs can play library pieces, chosen at random from the kinds the teacher picks.

The library window filters by kind, searches titles, composers and styles, plays the measures chosen, has "🎲 Pick at random", and says why measures can't be used.

The pieces are in `library/data.js` and the scores in `library/` (engraved hymns as gzipped SVG, piano pages as 1-bit PNG), loaded only when needed; a one-line-a-piece index is bundled so a Terms quiz chooses the same pieces everywhere. Pieces are only ever added, each with the library version it arrived in. `tools/library/` holds the scripts that build it and their sources (see its README).

### Retakes

Every Clefwork page ends a quiz with a **Retake quiz** button: the same quiz code, so the same questions, and a fresh start. Retakes are unlimited unless the teacher sets a limit under **Quiz rules** (none, or 1–10 retakes). The limit travels in the quiz code; quizzes without one keep exactly the codes they had.

A student's device counts their attempts and stops offering retakes once the limit is used. Because there's no server, a student could start again on another device — so every report code also records its attempt number, and the grade checker and results pages show it ("Attempt 2"), with a warning when an attempt goes past the quiz's limit. Report codes became version 9 with this (version 10 added rhythm answers, 11 their note scores, 12 melodies, 14 rhythm grids).

### Canvas

"Set up in Canvas" on the teacher's share card gives everything needed to run a quiz through a Canvas assignment. The first box, pasted into the assignment's HTML editor, is the whole description: the steps, the quiz embedded under them (it asks Canvas to resize its frame to fit), and a link to open it in its own tab for tablets, phones and the Canvas app. There is also a link-only description for schools that block embedded sites, the bare quiz link, and an optional number of points the quiz is worth in Canvas. Students take the quiz on `take.html`, then submit their results link as a **Website URL**. SpeedGrader shows a snapshot of each student's results page — name, score, the score scaled to the Canvas points, and every answer — with a link to the live page.

Canvas can't receive the grade by itself: that needs an LTI tool running on a server, which this app deliberately doesn't have. The teacher types the score from SpeedGrader. Correct answers stay off shared results pages unless the quiz lets students check answers; on the computer the quiz was built on, the results page marks everything against the saved quiz.

### Printing

The **Print** tab makes a paper copy of the current quiz: a header with the quiz title, teacher, course and date (mm/dd/yyyy, today's by default) and a blank for the student's name, then every question with a blank line beside its number for the point value, the printed example, and room to answer. Staves print at an inch or more — a grand staff 65% taller again, so there is room to write in both clefs — question text at 12pt, margins at 0.75 in (19 mm on A4), on Letter, Legal or A4. Every page carries a footer with the quiz ID and a QR code, captioned “Scan to take this quiz online”, that opens the quiz ready to take on the student page — scanned from paper, or clicked in the preview, the PDF or the Word document. The whole quiz travels in the link, so its code is written compactly (the quiz code in the QR code's alphanumeric mode), and the Print tab suggests a larger size when a long quiz makes a fine code. A quiz link that can't be opened says why, rather than showing the last quiz taken on that device. The preview zooms to fit a whole page, with a slider for a closer look. "Save as PDF" writes the PDF itself — the staves are drawn as line work, so they stay sharp at any size — and "Export Word" writes a .docx with the staves as pictures.

## Building

Everything is plain HTML, CSS and JavaScript with no build dependencies — including the QR encoder, the PDF writer, the PNG writer and the Word (.docx) writer. `./build.sh` concatenates `src/` into the files in `dist/`:

```
dist/clefwork.html                    teacher app, body only (for embedding)
dist/clefwork-standalone.html         teacher app, complete page
dist/clefwork-student.html            student app, body only
dist/clefwork-student-standalone.html student app, complete page
dist/clefwork-keys*.html              Clefwork Keys
dist/clefwork-analysis*.html          Clefwork Analysis
dist/clefwork-rhythm*.html            Clefwork Rhythm
dist/clefwork-melody*.html            Clefwork Melody
dist/clefwork-graph*.html             Clefwork Chord Graph
dist/clefwork-terms*.html             Clefwork Terms
dist/site/library/                    the library's pieces and score pictures (copied from library/)
dist/clefwork-take-standalone.html    Canvas: take one quiz
dist/clefwork-results-standalone.html Canvas: one student's results
dist/site/                            copies published to GitHub Pages
```

Set `CLEFWORK_BASE` before building to change the address used in shared links.
